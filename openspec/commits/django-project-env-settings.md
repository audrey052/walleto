## Why this is recorded here

First code in the repository. It fixes the project layout (`config/` package at the root) that every later app builds on, and it is the commit that introduces the `setup-foundation` change itself (proposal, design, tasks and three specs) and the project-wide OpenSpec context.

## Context

- **Layout:** `django-admin startproject config .` puts settings in `config/` and `manage.py` at the root, so apps live next to it (`accounts/`, `core/`, later `finance/`). See `design.md` decision 1.
- **Secrets move to `.env`** through python-dotenv. The repository is public, so the generated `django-insecure-…` key could not stay in `settings.py`.
- **`migrate` was deliberately not run.** The custom user model (next commits) must exist before the first migration; running `migrate` now would create Django's default `auth_user` table and lock it in. The empty `db.sqlite3` that `runserver` created had no tables.

## What is built

### Settings (`config/settings.py`)

| Setting | Value | Why |
|---|---|---|
| `load_dotenv(BASE_DIR / ".env")` | after `BASE_DIR` | `.env` sits at the repository root |
| `SECRET_KEY` | `os.environ["SECRET_KEY"]` | raises `KeyError` at startup when missing, instead of running without a key |
| `DEBUG` | `os.getenv("DEBUG", "False") == "True"` | `.env` values are strings and `bool("False")` is `True`; defaults to `False` so production never runs in debug by accident |
| `TEMPLATES["DIRS"]` | `[BASE_DIR / "templates"]` | project-wide templates at the root |
| `STATICFILES_DIRS` | `[BASE_DIR / "static"]` | CSS, JS and fonts at the root |
| `TIME_ZONE` | `"Asia/Jakarta"` | users are in Indonesia; dates must follow their day |
| `LANGUAGE_CODE`, `USE_TZ` | `"en-us"`, `True` | defaults kept; UI is English |

### Environment template (`.env.example`)

`SECRET_KEY=`, `DEBUG=`, `OPENAI_API_KEY=` with no values. `.env` itself is git-ignored.

### OpenSpec

- `openspec/config.yaml`: project context (English artifacts, stack, English UI, light mode only, Rupiah never float, numbers computed by code not the LLM, data scoped per user) and per-artifact rules.
- `openspec/changes/setup-foundation/`: proposal, design (10 decisions), tasks, and specs `user-auth`, `app-shell`, `money-format`.

## Requirements this establishes

1. **No secret is committed.** Every secret is read from the environment; `.env.example` documents the names only.
2. **The app refuses to start without `SECRET_KEY`.**
3. **Debug is off unless explicitly enabled** with `DEBUG=True`.
4. **Dates are computed in Asia/Jakarta time.**
