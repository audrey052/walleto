## Differences from the plan

- **Sign-in required through `LoginRequiredMiddleware`** instead of decorators on each view. Safer default: new views are private unless marked `@login_not_required`. Recorded in `design.md` decision 4.
- **Simple components are CSS classes, not include files.** Buttons, inputs and panels are classes (`btn btn-primary`); only structured components are includes. Icons are a template tag instead of `components/icon.html`. Recorded in `design.md` decision 7.
- **Label class renamed from `overline` to `eyebrow`**, because Tailwind's own `overline` utility drew a line above the text.
- **Mobile account menu** lives in the topbar (avatar button), since the sidebar is hidden below 768px.
- **Extra component:** `page_heading.html`. **Extra tests:** app shell tests (task 9.7).
